My first game in C
======================

As I mentioned in the [previous post](https://blog.calebe.dev.br/posts/Que-tal-criar-um-jogo.html),
I'm planning to create a game in **C** using the **SDL2** library.

So to "get the hang of" how to build a game with **SDL2**,
I followed a YouTube tutorial called [Game Programming in C using SDL](https://www.youtube.com/watch?v=B4BXpiQASpA).

The project can be found at the link below:

- [sdl2-pong - Pong but written in C using SDL2.](https://git.calebe.dev.br/sdl2-pong/)

I didn't find building the game complicated at all. **SDL2** has a really
nice abstraction for detecting collisions and I had no issues during
the construction of the game.

In the future I plan to add sound effects and sprites to the game.

I also plan to create a web demo of the game, using Web Assembly.

Well... that's it for now.

See you next time!
